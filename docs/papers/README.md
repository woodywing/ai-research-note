# Papers and Source Documents

個別の論文、PDF、技術ドキュメント、社内メモなどに対応する読書メモを置くディレクトリです。

## Recommended file name

```text
YYYY-author-short-title.md
```

例:

```text
2024-smith-tabular-transformers.md
```

## Recommended workflow

1. `docs/templates/paper-note.md` をコピーする。
2. ソース固有の事実、主張、実験条件、限界を記録する。
3. トピック横断で再利用したい内容は `docs/topics/` 配下の該当ノートへ反映する。
